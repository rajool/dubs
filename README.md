# dubs

Unlisted watch pages for Persian dubs of public talks, served by GitHub Pages at `https://rajool.github.io/dubs/<slug>/`.

Each folder is one video: the player page (`index.html`), the Persian dub audio (`dub.m4a`), Persian and English subtitles (`fa.vtt`, `en.vtt`) and the page font. The video itself streams from YouTube; the page mutes it and plays the dub in sync. A `#party=<unix seconds>` link starts everyone at the same moment.

The pages carry `noindex`. The dubs are unofficial Persian translations voiced by AI, and each page says so. A dub may use voices that AI modelled on the speakers' own voices (`rethinking-venture` does); the speakers did not record or approve them, and the dubs are not affiliated with the original publishers.
